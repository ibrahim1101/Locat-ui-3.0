# Known limitations

FEATURE_MATRIX.md and CONNECT_IMPLEMENTATION_TRACKER.md are the current evidence inventory. Private conversations/E2EE, federation, authenticated global authority/key lifecycle, device-authorized real-time subscriptions, real TURN fallback acceptance, native hosts and public deployment remain incomplete. No public service is activated. Browser server changes isolate rather than migrate data. Persistent UUID is not cryptographic trust. Proxy-mode authentication rates aggregate by socket peer. Docker/Cloudflare templates are unexecuted. Shared media roots are readable by all registered accounts and are not Vaults. Experimental private encryption has no independent review. Existing per-module documentation retains detailed limits; no full-roadmap completion is asserted.

Experimental Matrix binding/bootstrap and optional managed application-service provisioning are implemented. Explicit logout of the initialized token and deletion of the current derived managed Matrix device are tested against Synapse. Account-wide session inventory, arbitrary other-device removal, coordinated Link/Matrix revocation jobs and full identity recovery remain pending. The production HTTPS auth/proof boundary now has loopback acceptance; actual browser persistence and UI acceptance remain pending. See MATRIX_ACCOUNT_BINDING.md. Existing Matrix device private keys cannot be imported using an access token. Conversation APIs remain gated.
